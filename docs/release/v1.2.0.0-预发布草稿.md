# SVL v1.2.0.0 · 新架构预览版

距离上一次正式版发布已有七个月。这段时间里，我们把 SVL 从 Windows 上的 WPF 应用迁移到了 Avalonia，为 Windows、macOS 和 Linux 带来了统一的启动器体验，也持续完善了实例、Mod 与整合包管理。

这是新架构的首个预览版。欢迎使用副本或测试实例体验，并反馈迁移、安装和下载过程中遇到的问题。

**如何选择：**自带运行环境的版本开箱即用，推荐大多数用户；轻量版体积更小，需要先安装与系统架构一致的 [.NET 10 Runtime](https://dotnet.microsoft.com/download/dotnet/10.0)（包含 `Microsoft.NETCore.App`）。Linux 轻量 DEB 声明了 `dotnet-runtime-10.0` 依赖，若软件源尚未提供，请参照 [Ubuntu](https://learn.microsoft.com/dotnet/core/install/linux-ubuntu-install) 或 [Debian](https://learn.microsoft.com/dotnet/core/install/linux-debian) 安装指南配置软件源。也可运行 `dotnet --list-runtimes` 检查。

## 这次有哪些变化

### 跨平台与界面

- 使用 Avalonia 和 .NET 10 重建启动器，提供 Windows、macOS 和 Linux 版本。
- 重新整理主页、版本设置、下载与任务页面，支持浅色和深色主题、自定义配色与窗口透明度。
- 调整实例图标、自定义鼠标指针、弹窗和窗口控件，改善不同页面的一致性。

### 游戏实例与 SMAPI

- 管理多个游戏路径和独立版本，支持原版、SMAPI 及整合包实例。
- 完善 SteamCMD 跨平台下载和游戏路径识别，改进 SMAPI 安装流程。
- 首次启动时尝试迁移旧版配置与实例列表，保留原有配置文件和游戏目录。

### Mod 与整合包

- 在 Mod 管理中查看依赖、检查更新、启用或禁用 Mod，并支持备份和恢复。
- 改进批量更新、覆盖前备份和冲突处理；为包含多个子 Mod 的安装包保留来源信息。
- 支持 SVL 整合包导入与导出，改进 CurseForge Modpack 和 Nexus Collection 安装流程、下载进度及自定义图标处理。
- 接入 NexusMods、CurseForge、GitHub 和社区本地化数据，支持浏览资源与管理下载任务。

### 下载、设置与稳定性

- 完善多线程下载进度、缓存复用和启动后任务恢复。
- 改进 Nexus 登录回调、主题适配和设置保存。
- 兼容旧版匿名统计标识，避免升级时将同一安装重复计为新用户。

## 旧版用户升级

新版会尝试读取旧版配置与实例列表，但从 WPF 正式版通过应用内更新直接升级到此预览版的完整流程仍需实机验收。测试前请备份启动器配置及重要游戏数据。

预发布后，旧版用户测试在线更新时，请将首选更新源设为 **GitHub**，启用 **检查预发布版本**，再手动检查更新。Windows 的 `SVL.Desktop_v1.2.0.0_Release.exe` 是供旧版更新器使用的自包含单文件程序；它不是安装向导。

## 已知事项

- macOS 安装包目前使用临时签名，尚未进行 Apple 公证；首次打开可能需要在系统设置中允许。Apple Silicon 上运行 Intel 版 SteamCMD 需要 Rosetta 2。
- macOS / Linux 的 SteamCMD、真实账号在线下载及整合包安装仍需更多环境验证。
- 当前统计按匿名安装标识去重，更接近安装数量；24 小时活跃数基于成功上报，不等同于实时在线人数。可设置环境变量 `SVL_DISABLE_ANON_TELEMETRY=1` 关闭匿名上报。
