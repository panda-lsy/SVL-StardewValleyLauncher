**如何选择：** 日常使用推荐 Release；Debug 适合排查问题。自带环境版本不需要单独安装 .NET；轻量版需要先安装与系统架构一致的 [.NET 10 Runtime](https://dotnet.microsoft.com/download/dotnet/10.0)，可以运行 `dotnet --list-runtimes` 检查。Linux 轻量 DEB 声明了 `dotnet-runtime-10.0` 依赖，若软件源尚未提供，请参照 [Ubuntu](https://learn.microsoft.com/dotnet/core/install/linux-ubuntu-install) 或 [Debian](https://learn.microsoft.com/dotnet/core/install/linux-debian) 安装指南配置软件源。

**Windows：** 下载 EXE 后即可直接运行；自带环境 Release EXE 也可用于旧版更新。Windows 与 Linux 的 Debug 程序已内嵌应用调试符号，不需要额外下载 PDB 才能运行。

**Linux：** DEB 可使用软件安装器或 `sudo apt install ./下载的文件名.deb` 安装。免安装版下载后，先执行 `chmod +x ./下载的文件名`，再运行 `./下载的文件名`。Release 与 Debug 的 DEB 使用相同的软件包名，不能同时安装；从 Release 切换到 Debug 时可能需要允许软件包降级。

**macOS：** 打开 DMG 后，将应用拖入 Applications。

Release 与 Debug 共用启动器数据，切换前建议备份重要配置。为兼容现有更新器和已经分享的链接，必要的 ZIP 文件仍保留在下方 Assets 中。所有文件的校验值见 [SHA256SUMS.txt](https://github.com/panda-lsy/SVL-StardewValleyLauncher/releases/download/<标签>/SHA256SUMS.txt)，更新说明见 [update.txt](https://github.com/panda-lsy/SVL-StardewValleyLauncher/releases/download/<标签>/update.txt)。
