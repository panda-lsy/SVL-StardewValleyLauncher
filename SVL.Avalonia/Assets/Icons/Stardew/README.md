# 游戏界面素材

此目录保存游戏界面像素素材，包括用户提供的图像。应用直接加载文件，按原有比例显示，
不重新裁切或改写图像；素材尺寸可以各不相同。

- `Enable.png` / `Disable.png`：Mod 可执行的启用或禁用操作。
- `Catalog.png` / `Export.png` / `Info.png`：打开目录、导出和说明。
- `Cursor/Cursor.png`：窗口默认指针，热点为左上角 `(0, 0)`。
- `Cursor/` 中其他指针及 Gamepad 素材目前保留，后续适配时使用。

原启动器品牌图标及 SMAPI 图标位于 `Assets/Icons/icon.png`、`icon.ico` 和 `Modded.png`，
不是本目录内的替代预设。游戏素材版权归原权利人所有，使用和再分发应遵循相应授权。
