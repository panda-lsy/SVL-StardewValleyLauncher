# Mod Icon Placeholder

This folder should contain default mod icons used by the launcher.

## Recommended Icons

- **default_mod.png** - Generic mod icon (80x80)
- **disabled_mod.png** - Disabled mod icon (80x80)

## Note

For the initial version, the application will use a default placeholder
from the resource dictionary. You can replace this with actual icon files.

## Icon Guidelines

- Size: 80x80 pixels
- Format: PNG with transparency
- Style: Clean, recognizable at small sizes
- Background: Transparent

You can find free mod icons at:
- https://www.iconarchive.com/
- https://www.flaticon.com/
- https://game-icons.net/
